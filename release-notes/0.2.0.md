## Overflow progression

- When a sector has reached its configured active-boss maximum, administrators and automatic spawning can level up a random active boss group instead of creating another group.
- Overflow progression reduces threat by one configured threshold, never below zero, and uses the normal level-up announcement.

## Settings and stability

- Boss spawn settings are fully localized in the in-game plugin settings panel.
- Combat handling safely ignores unavailable NPC instances.
