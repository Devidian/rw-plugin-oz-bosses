## Initial boss encounters

- Adds persistent boss groups with followers, threat-based levels, health scaling, combat rankings, configurable loot, and optional Wallet bounties.
- Ships nine separately balanced default groups ranging from skeletons and wolves to lions and fire wolves.
- Supports editable group definitions with individual health progression, follower NPC type, minimum player distance, display name, and random-spawn weight overrides.
- Gives every default group its own male and female name lists and tiered loot table.
- Keeps active group identity and configuration references across plugin reloads.
- Includes administrator controls for spawning, inspecting, and removing boss groups.

OZ Tools 0.23.8 is required.
